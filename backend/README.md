# FreelanceFlow Backend

Laravel 13 API for the FreelanceFlow application.

## Included

- Sanctum SPA/session authentication
- Registration, login, logout and current-user endpoint
- Email verification and password reset
- Client CRUD with authorization policies
- Invoice CRUD, yearly invoice numbering and invoice items
- Payment recording and balance/status updates
- PDF invoice generation with DomPDF
- M-Pesa STK Push + callback handling
- Business profile and logo upload
- Dashboard summaries
- Revenue, invoice, client and payment reports
- Database notifications and email reminders
- Audit log records
- Scheduled overdue/reminder commands
- Feature tests

See the repository root README for complete setup instructions.
